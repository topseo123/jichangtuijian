## 下单前，把自己的需求换算成套餐条件

1. **预算与流量：**先估算月用量，再比较月付总价和节点倍率。年付折算便宜，也要考虑实际一次支付金额。
2. **宽带与时段：**在常用的电信、联通或移动网络下，测试工作日 20:00—23:00 的网页响应、视频播放与持续连接。
3. **客户端与设备：**Clash 机场需确认开放订阅、内核兼容及设备限制；依赖官方客户端的服务，先检查系统支持范围。
4. **目标地区与服务：**围绕实际使用的视频、办公和 AI 工具测试。家宽、原生 IP、IEPL 都是筛选条件，不能单独保证访问或速度。

例如，200GB 套餐如果始终使用 2 倍率节点，可承载的实际传输量约为 100GB；¥12/年的套餐折合 ¥1/月，但首次支付仍是 ¥12；130GB 不限时包则是总共 130GB，不会下个月再发一份。把这三种计费方式分清，比单纯寻找最低价格更实用。

首次购买先用短周期确认常用节点，再决定是否续费。工作离不开订阅时，可以准备另一家服务商的备用，并定期检查连接。

## 机场推荐常见问题

### 哪个机场最稳定？

不存在适合所有宽带和地区的唯一答案。先从符合预算、客户端和地区需求的名单中选择，再比较自己的晚高峰体验。稳定性要看持续连接和故障恢复，不能只看一次测速峰值。

### 便宜机场能当主力吗？

可以测试，但要看流量是否够用、常用节点是否持续可用，以及故障时是否有人维护。低价月付、低流量年付和不限时包适合的使用方式不同，不能仅按价格排序。

### Clash 机场推荐应该关注什么？

重点看是否提供标准订阅、所用内核是否支持节点协议，以及节点是否只能在官方客户端中使用。买完能导入只是第一步，还要确认更新订阅、切换节点和分流能正常工作。

### IEPL/IPLC 专线一定比直连快吗？

不能保证。线路容量、节点负载和本地路由都会影响结果。服务商还可能临时切换线路，因此应比较当前节点表现，而不只看套餐名称。

### 不限时机场适合每天看视频吗？

取决于流量单价和实际消耗。低频使用不用担心月度额度闲置；每天大量用流量时，月付套餐可能更合适。不按月清零，也不意味着服务能够永久持续。

### 机场节点全部连接失败怎么办？

先检查套餐有效期和剩余流量，更新订阅，再切换手机热点排除本地网络问题。如果多台设备、多个网络都无法连接，查看公告或提交工单，并切换备用服务。

### 机场应该月付还是年付？

首次使用优先选择月付或最短周期，确认常用节点、用量和售后符合需求后再决定。不要只凭折扣直接购买多年套餐，也不要把年付折算月价和真正月付价格混为一谈。
